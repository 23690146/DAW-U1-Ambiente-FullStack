# Ambiente Full Stack

## Asignatura

Desarrollo de Aplicaciones Web

## Tecnologías

- Vue
- Vite
- PHP
- Apache
- MySQL
- Docker
- Docker Compose
- Git

## Arquitectura

Frontend -> Backend -> Base de datos

## Instalación

1. Clonar el repositorio.
2. Crear el archivo `.env`.
3. Instalar las dependencias.
4. Construir los contenedores.
5. Levantar Docker Compose.

## Comandos

```bash
docker compose build
docker compose up -d
docker compose ps
docker compose down
